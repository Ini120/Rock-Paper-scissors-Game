# Rock Paper Scissors

A simple and responsive Rock Paper Scissors game built with HTML, CSS, and JavaScript.

This project was created as part of my JavaScript learning journey to practice programming logic, functions, conditionals, random numbers, and DOM manipulation.

## Features

* Rock, Paper, and Scissors game choices
* Computer-generated random moves
* Win, lose, and tie results
* Score tracking
* Reset score functionality
* Responsive design
* Interactive button effects

## Technologies Used

* HTML5
* CSS3
* JavaScript

## Concepts Practiced

* JavaScript functions
* Variables and constants
* Conditional statements
* Comparison operators
* `Math.random()`
* Template literals
* DOM manipulation
* Flexbox
* CSS media queries
* Responsive web design

## How to Run

1. Clone the repository:

```bash
git clone https://github.com/Ini120/Rock-Paper-scissors-Game.git
```

2. Open the project folder.

3. Open `index.html` in your browser.
